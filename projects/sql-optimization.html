PROJECT NOTES / 03


Project overview
Academic work in SQL query tuning and data warehousing. I inspected execution plans with EXPLAIN, refactored slow nested subqueries into appropriate JOIN patterns, and introduced targeted indexes where query access patterns justified them.


My contributions
  • Read SQL execution plans to investigate slow-running queries.
  • Refactored nested queries into JOIN patterns when appropriate.
  • Applied column indexing to improve query access paths.
  • Used relational schema design, ETL principles, and data warehousing fundamentals on analytical datasets.


Engineering approach
Performance work started with understanding access patterns rather than changing syntax at random. The goal was to inspect plans, understand why a query scanned more than necessary, and choose a better strategy.


How the pieces connect
Read EXPLAIN→Find bottlenecks→Refactor JOINs→Index columns→Re-check access plan
