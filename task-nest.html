Behind the build.

PROJECT NOTES / 01

Project overview

Task Nest is a final-year project connecting local service vendors with customers. Its full-stack implementation covers separate onboarding flows, authentication logic, relational data models, service discovery, and bookings.

My contributions

  • Designed a relational data structure in PostgreSQL and Supabase to support service listings and role-specific workflows.
  • Implemented TypeScript-based application behavior for vendor and customer journeys.
  • Manually tested authentication, listings, booking flows, validation, usability, and edge cases.
  • Documented defects with reproduction steps and expected-versus-actual outcomes.

Engineering approach

The main engineering problem was keeping the two user roles and their workflows understandable and consistent. Testing focused on form validation, application states, and booking flow edge cases.

How the pieces connect

Role selection→Account / access→Service listings→Booking workflow→QA & validation
